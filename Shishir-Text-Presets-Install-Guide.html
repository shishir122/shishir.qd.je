0শুরুর আগে

এই তিনটা জিনিস থাকলেই হবে।

Premiere Pro 2020 বা নতুনWindows বা Mac, দুটোতেই চলে।
ইন্টারনেট সংযোগসাইন-ইন আর নতুন প্রিসেট নামানোর জন্য লাগে।
ZIP ফাইল Extract করাZIP-এর ভেতর থেকে চালাবেন না। আগে ডান ক্লিক করে Extract All করুন।
ইনস্টলের আগে Premiere Pro পুরোপুরি বন্ধ রাখুন।

1Windows: এক ক্লিকে ইনস্টল

সবচেয়ে সহজ এবং সবচেয়ে নিশ্চিত উপায়।

প্রস্তাবিত
  1. ডাউনলোড করা ZIP ফাইলটা Extract করুন।
  2. ভেতরের Install-Windows.bat ফাইলে ডাবল ক্লিক করুন।
    না চললে ফাইলে ডান ক্লিক করে Run as administrator বেছে নিন।
  3. কালো উইন্ডোতে Done! লেখা এলে উইন্ডো বন্ধ করুন।
  4. Premiere Pro খুলুন।
Premiere Pro-র Window → Extensions মেনুতে Shishir Text Presets নাম দেখা যাবে।

2Mac: এক ক্লিকে ইনস্টল

  1. ZIP ফাইলটা Extract করুন।
  2. Install-Mac.command ফাইলে ডাবল ক্লিক করুন।
    না খুললে ফাইলে ডান ক্লিক করে Open চাপুন, তারপর আবার Open।
  3. টার্মিনালে Done! লেখা এলে বন্ধ করুন।
  4. Premiere Pro খুলুন।
Window → Extensions → Shishir Text Presets দেখা যাবে।

3ZXP/UXP Installer দিয়ে (ড্র্যাগ ও ড্রপ)

যারা ZXP/UXP Installer অ্যাপ ব্যবহার করেন তাদের জন্য। এক ক্লিক ইনস্টল কাজ করলে এই অংশ দরকার নেই।

বিকল্প
  1. প্রথমে একবার 1-Enable-Unsigned-Plugins.reg ফাইলে ডাবল ক্লিক করে Yes দিন। (Windows)
    এটা না করলে Premiere সাইন-না-করা প্লাগইন দেখাবে না।
  2. Premiere Pro বন্ধ করুন।
  3. ZXP/UXP Installer খুলুন, তারপর .zxp ফাইলটা ড্র্যাগ করে অ্যাপের ওপর ছেড়ে দিন।
  4. তালিকায় Shishir Text Presets এলে Premiere Pro খুলুন।
Window → Extensions মেনুতে Shishir Text Presets আছে।
ইনস্টলার আটকে গেলে বা ত্রুটি দিলে ওপরের এক-ক্লিক পদ্ধতি ব্যবহার করুন।

4প্রথমবার ব্যবহার

  1. Premiere Pro-তে একটা প্রজেক্ট এবং একটা সিকোয়েন্স (টাইমলাইন) খুলুন।
  2. Window → Extensions → Shishir Text Presets চাপুন। প্যানেল খুলবে।
  3. Account ট্যাবে গিয়ে ইমেইল দিয়ে সাইন-ইন করুন (বা লাইসেন্স কী বসান)। নতুন হলে ফ্রি ট্রায়াল শুরু হবে।
  4. টাইমলাইনে যেখানে টেক্সট চান সেখানে প্লেহেড (নীল দাগ) রাখুন।
  5. Presets ট্যাব থেকে পছন্দের প্রিসেটে Insert চাপুন। প্লেহেডের জায়গায় টেক্সট বসে যাবে।
  6. Essential Graphics প্যানেল থেকে লেখা, রং, ফন্ট বদলে নিন।
টাইমলাইনে প্রিসেটের ক্লিপ বসেছে এবং চালালে অ্যানিমেশন দেখা যাচ্ছে।
Search ও ক্যাটাগরিনাম লিখে খুঁজুন, বা Effects, Colors ইত্যাদি ক্যাটাগরি বেছে নিন।
Favপছন্দের প্রিসেটে Fav চাপলে সেটা Favorites ট্যাবে জমা হয়।
New ট্যাবনতুন প্রিসেট অনলাইন থেকে নিজে আসে। আবার ইনস্টল করতে হয় না। নতুনগুলোতে NEW ব্যাজ থাকে।
Trackকোন ভিডিও ট্র্যাকে বসবে সেটা Track ঘরে ঠিক করা যায়। শুরুতে top লেখা থাকে।

প্লাগইন ঠিকমতো চলছে কিনা দেখুন

Presets ট্যাবে প্রিসেট সংখ্যার পাশে ONLINE লেখা থাকলে প্লাগইন সার্ভারের সাথে যুক্ত এবং নতুন প্রিসেট পাচ্ছে। OFFLINE লেখা থাকলে ইন্টারনেট বা অন্য সমস্যা আছে, নিচের সমস্যা সমাধান দেখুন।

5সমস্যা হলে কী করবেন

প্রতিটা সমস্যার ওপর চাপ দিন।

Window → Extensions মেনুতে প্যানেল নেই
  1. Premiere Pro পুরোপুরি বন্ধ করে (Task Manager-এ থাকলে সেটাও) আবার খুলুন।
  2. Windows-এ Install-Windows.bat-এ ডান ক্লিক করে Run as administrator দিয়ে আবার চালান।
  3. Mac-এ Install-Mac.command আবার চালান।
  4. ZXP দিয়ে ইনস্টল করলে 1-Enable-Unsigned-Plugins.reg চালিয়েছেন কিনা দেখুন।
আগে পুরনো ভার্সন (১.১.x) ইনস্টল ছিল, এখন দুটো দেখাচ্ছে বা নতুন প্রিসেট আসছে না
  1. পুরনো ভার্সনটা Window → UXP Plugins মেনুর নিচে থাকে। ZXP/UXP Installer খুলে পুরনো Shishir Text Presets-এ Remove চাপুন।
  2. Premiere Pro বন্ধ করে আবার খুলুন।
  3. এরপর শুধু Window → Extensions থেকে নতুনটা খুলুন।
সাইন-ইন হচ্ছে না
  1. ইন্টারনেট চালু আছে কিনা দেখুন।
  2. ওয়েবসাইট shishir.qd.je-এ যেই ইমেইল দিয়ে অ্যাকাউন্ট করেছেন, প্লাগইনে হুবহু সেই ইমেইল দিন।
  3. লাইসেন্স কী থাকলে সেটা Account ট্যাবে বসিয়ে দেখুন।
“computers limit” বা কম্পিউটারের সংখ্যা শেষ বলছে
  1. ব্রাউজারে shishir.qd.je-তে সাইন-ইন করে My account খুলুন।
  2. লাইসেন্স অংশে Free my computers চাপুন।
  3. আবার প্লাগইনে সাইন-ইন করুন।
নতুন প্রিসেট আসছে না বা সংখ্যা বাড়ছে না
  1. প্যানেল বন্ধ করে আবার খুলুন। খোলার সময় নতুন তালিকা নামে।
  2. প্রিসেট সংখ্যার পাশে ONLINE আছে কিনা দেখুন।
  3. OFFLINE দেখালে ইন্টারনেট, VPN বা ফায়ারওয়াল দেখুন। লেখাটা স্ক্রিনশট করে WhatsApp-এ পাঠান।
Insert চাপলে কিছু বসছে না
  1. একটা প্রজেক্ট এবং সিকোয়েন্স খোলা আছে কিনা দেখুন।
  2. টাইমলাইন প্যানেলে একবার ক্লিক করে সেটা সক্রিয় করুন, তারপর আবার Insert চাপুন।
  3. লাল বার্তা এলে সেটা স্ক্রিনশট করে WhatsApp-এ পাঠান।
লাইসেন্স বা ট্রায়াল শেষ হয়ে গেছে

ওয়েবসাইটে সাইন-ইন করে shishir.qd.je → Plugin পেজে প্ল্যান দেখুন। পেমেন্ট বা লাইসেন্স নিয়ে সাহায্য লাগলে WhatsApp-এ জানান।
